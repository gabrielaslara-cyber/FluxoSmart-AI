# Publicação do FluxoSmart AI 2.0

Esta branch contém uma versão experimental do dashboard. O aplicativo ainda não utiliza IA generativa.

## Deploy no Streamlit Community Cloud

1. Acesse https://share.streamlit.io/ e entre com o GitHub.
2. Escolha o repositório `gabrielaslara-cyber/FluxoSmart-AI`.
3. Selecione a branch `feature/fluxosmart-2-dashboard`.
4. Use `app.py` como arquivo principal.
5. Publique e verifique os gráficos, filtros, importação e exportação.

O deploy exige autenticação da proprietária. Não envie dados sigilosos ao aplicativo demonstrativo.

## Testes

Execute `python -m pytest -q`. O GitHub Actions também executa os testes automaticamente.
