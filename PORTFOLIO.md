# Portfólio — FluxoSmart AI Premium

**Autoria:** Gabriela de Souza Lara

**Demonstração pública:** https://fluxosmart-ai-premium.streamlit.app/

## Descrição curta para currículo

Desenvolvimento de aplicação web demonstrativa em Python e Streamlit para importar planilhas de vendas, validar e analisar dados com Pandas, criar dashboards e gerar relatórios gerenciais PDF com ReportLab. Implementação de diagnósticos descritivos e testes automatizados com pytest.

## Evidências verificadas

- Aplicativo publicado no Streamlit Community Cloud
- Dashboard de vendas com indicadores e filtros
- Diagnósticos descritivos e plano de ação
- PDF Premium com duas páginas, gráficos, indicadores, data de emissão e recomendações
- Testes com dados fictícios; módulo de análise de vendas separado da interface

## Limites e transparência

Este é um projeto demonstrativo, **não um produto validado para produção**. Os dados de exemplo são fictícios. Os diagnósticos são baseados em regras e não usam IA generativa. É necessário testar integração, desempenho, segurança e conjuntos de dados maiores antes de uso empresarial.
